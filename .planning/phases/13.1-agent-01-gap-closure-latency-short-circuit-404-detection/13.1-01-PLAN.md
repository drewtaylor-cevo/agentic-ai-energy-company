Amend `agent/agent.py::_BASE_SYSTEM_PROMPT` to add two load-bearing prompt clauses that close Phase 13's Gap 1 (mechanism) and Gap 2 (prompt-side half):

1. **SHORT-CIRCUIT RULE (D-13.1-14):** When `detect_bill_shock` returns `is_shock=False`, skip `get_billing_history` AND skip calling `detect_bill_shock` again — non-shock personas follow the 2-tool path `get_hardship_flag → simulate_savings`. Gap 2 is caused by the same prompt letting the LLM synthesise UNKNOWN placeholder tracks instead of routing empty-billing to the errorMessage branch. This plan is the prompt-side fix for both.
