# Phase 13.1 Plan 03: Api-Lambda UNKNOWN-Plan_Id Sentinel + Live Smoke Canary Summary

## One-liner

Added HTTP-404 defence-in-depth sentinel branch to `api_lambda/handler.py` that catches `plan_id == "UNKNOWN"` on either track, plus 2 offline handler tests and 1 live-smoke canary (`test_agent01_non_shock_stays_2_tools`) for Plan 04 Wave 2 ceremony verification.

## Objective

Close Gap 2's API-boundary half by appending a new `if` branch to `api_lambda/handler.py` (immediately after the existing D-12 "no green/cheapest keys" 404 heuristic) that returns HTTP 404 when the agent disobeys the EMPTY BILLING STOP rule (Plan 01) and synthesises placeholder `"UNKNOWN"` tracks. Additionally, register the D-13.1-16 live smoke canary for the non-shock 2-tool flow so Plan 04 ceremony can verify the prompt SHORT-CIRCUIT RULE fires in production on the real stack.

Primary Gap 2 fix is the prompt-side STOP rule in Plan 01; this plan is the belt-and-braces API-boundary check for when the LLM disobeys the prompt on a future Sonnet/Strands bump (D-22 pin is mechanical, but boundary checks are defensive).
