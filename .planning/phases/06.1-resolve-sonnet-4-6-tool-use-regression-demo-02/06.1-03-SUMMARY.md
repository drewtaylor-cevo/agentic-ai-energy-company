**2. [Rule 1 - Bug] Plan's CloudWatch `--query 'Datapoints[*].Sum | join(\`+\`, @)'` is syntactically wrong**

- **Found during:** Task 2 Step 2 verify block
- **Issue:** The plan's `<automated>` verify block uses JMESPath `join()` on `Datapoints[*].Sum`, but `Sum` values are floats (e.g., `2.0`, `1.0`) and JMESPath `join()` requires string-typed arrays — AWS CLI returns `In function join(), invalid type for value: 2.0, expected one of: ['array-string'], received: "float"`.
- **Fix:** Replaced with `--query 'Datapoints[*].Sum' --output text | awk '{for(i=1;i<=NF;i++) s+=$i} END {print s}'` for scalar sum computation. Also confirmed sum via `--query 'Datapoints[*].[Timestamp,Sum]'` for visible per-bucket breakdown.
- **Files modified:** None (runtime CLI-only).
- **Verification:** Sum across 20-min window = 2.0 + 1.0 = 3.0, matching the 3 canary runs exactly.
- **Committed in:** N/A (observability-only task; documentation-level fix for Plan 04).
