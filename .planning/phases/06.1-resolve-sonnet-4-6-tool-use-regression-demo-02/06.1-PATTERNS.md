```python
@tool
def simulate_savings(customer_id: str) -> dict:
    """Calculate Green and Cheapest tariff savings for a customer.

    Returns both recommendation tracks from the deterministic savings engine.
    The numbers returned are exact — do NOT recalculate, round, or estimate them.
    """
    if not _TOOLS_LAMBDA_ARN:
        raise RuntimeError("TOOLS_LAMBDA_ARN not set — agent misconfigured")

    resp = _lambda_client.invoke(
        FunctionName=_TOOLS_LAMBDA_ARN,
        InvocationType="RequestResponse",
        Payload=json.dumps({"customer_id": customer_id}).encode(),
    )
    payload = json.loads(resp["Payload"].read())
    if "FunctionError" in resp:
        raise RuntimeError(f"ToolsLambda error: {payload}")
    return payload
```

#### (8) New helper: extract lenient from AgentResult

Add NEW module-level helper (per RESEARCH §Salvage Path Under New API):

```python
def _extract_lenient_from_agent_result(
    agent_result: "AgentResult",
) -> "_RecommendationResponseLenient | None":
    """Pull the model's last attempt at RecommendationResponse input from message history.

    Zero-network alternative to issuing a third _agent(..., structured_output_model=_RecommendationResponseLenient) call.
    Returns None on any parse failure; caller falls back to the FALLBACKS bank.
    """
    if agent_result is None or agent_result.message is None:
        return None
    content_blocks = agent_result.message.get("content", []) or []
    for block in reversed(content_blocks):
        if not isinstance(block, dict):
            continue
        tool_use = block.get("toolUse") or block.get("tool_use")
        if tool_use and tool_use.get("name") == "RecommendationResponse":
            try:
                return _RecommendationResponseLenient(**tool_use.get("input", {}))
            except Exception:  # noqa: BLE001 — best-effort salvage
                return None
    return None
```

**Convention:** `# noqa: BLE001 — best-effort salvage` comment pattern matches existing `# noqa: BLE001` usage at L346 — keep the in-line rationale comment.

### Exception handling: catch → log → fallback → return valid body (D-04 never-500)

**Source:** `agent/agent.py` L327-391
**Apply to:** The migrated `invoke()` body.

Three-layer exception model to preserve:
1. **First try:** happy path (new API invocation). Sets `result = agent_result.structured_output`; raises `StructuredOutputException` on `None`.
2. **`except StructuredOutputException`:** per-field salvage via `_extract_lenient_from_agent_result` + `_narrative_fallback_salvage`. Marker flips to `"fallback"` per swapped field.
3. **`except Exception`:** catastrophic fallback — direct Lambda invoke, attach FALLBACKS narratives, marker all `"fallback"`, D-04 never-500 guarantee.

All three return `body["_narrative_source"] = narrative_source; return body` (L354-356, L390-391, L394-396).
