Stack-policy lift idiom:

```bash
# LIFT (per stack)
aws cloudformation set-stack-policy \
  --stack-name <StackName> \
  --stack-policy-body file://infrastructure/stack-policies/<stack>-allow-all.json \
  --profile cevo-dev25 --region us-east-1

aws cloudformation update-termination-protection \
  --no-enable-termination-protection \
  --stack-name <StackName> \
  --profile cevo-dev25 --region us-east-1

# DEPLOY (dependency order)
cdk deploy CustomerTariff --profile cevo-dev25 --require-approval never
cdk deploy CustomerTariffAgent --profile cevo-dev25 --require-approval never
# Optional (diff-conditional):
cdk deploy CustomerTariffApi --profile cevo-dev25 --require-approval never

# RE-APPLY (per stack, after byte-equivalence gate passes)
aws cloudformation set-stack-policy \
  --stack-name <StackName> \
  --stack-policy-body file://infrastructure/stack-policies/<stack>-freeze.json \
  --profile cevo-dev25 --region us-east-1

aws cloudformation update-termination-protection \
  --enable-termination-protection \
  --stack-name <StackName> \
  --profile cevo-dev25 --region us-east-1

# VERIFY (byte-equal freeze policy)
aws cloudformation get-stack-policy \
  --stack-name <StackName> --profile cevo-dev25 --region us-east-1 \
  | jq -r '.StackPolicyBody' \
  | diff - infrastructure/stack-policies/<stack>-freeze.json
```

- `CustomerTariff` -> `foundation-*.json`
- `CustomerTariffAgent` -> `agentcore-*.json`

for cust in CUST-001 CUST-002 CUST-003; do
  echo "=== $cust ==="
  pre="./planning/phases/13-bill-shock-multi-tool-flow-agent-01/baseline/pre/$cust.json"
  post=".planning/phases/13-bill-shock-multi-tool-flow-agent-01/baseline/post/$cust.json"
  # Extract SAV-03-sensitive fields only.
  pre_core=$(jq '{green: {plan_id: .green.plan_id, plan_name: .green.plan_name, saving_monthly: .green.saving_monthly, saving_annual: .green.saving_annual}, cheapest: {plan_id: .cheapest.plan_id, plan_name: .cheapest.plan_name, saving_monthly: .cheapest.saving_monthly, saving_annual: .cheapest.saving_annual}}' "$pre")
