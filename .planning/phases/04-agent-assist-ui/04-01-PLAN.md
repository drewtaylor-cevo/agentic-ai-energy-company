**Step 1 — Run `npx shadcn@latest init` inside `ui/`:**

Run the shadcn init command. Use the following preset selections (per UI-SPEC line 28):
- Style: `new-york`
- Base color: `slate`
- CSS variables: `yes`

This will install Tailwind CSS and its dependencies, create `components.json`, generate `ui/src/lib/utils.ts` (the `cn()` utility), and rewrite `ui/src/index.css` with Slate CSS variables + Tailwind directives.

If shadcn init prompts interactively, use: `npx shadcn@latest init --style new-york --base-color slate --css-variables`

Verify `components.json` contains `"style": "new-york"` and the path alias `@` resolves to `./src`.

**Step 2 — Add `@` path alias to tsconfig.app.json:**

shadcn init may or may not add this. Ensure `tsconfig.app.json` has:
```json
"compilerOptions": {
  "baseUrl": ".",
  "paths": { "@/*": ["./src/*"] }
}
```

Also ensure `tsconfig.json` references `tsconfig.app.json` (it should already).

**Step 3 — Update `ui/vite.config.ts`** to add path alias + Vitest config:

```typescript
/// <reference types="vitest" />
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'node:path'

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: { '@': path.resolve(__dirname, './src') },
  },
  test: {
    environment: 'jsdom',
    globals: true,
    setupFiles: ['./src/test-setup.ts'],
  },
})
```

**Step 4 — Install dev dependencies** (inside `ui/`):

```bash
npm install -D vitest @testing-library/react @testing-library/jest-dom jsdom
```

Also install runtime dependency:
```bash
npm install lucide-react
```
