**File 1 -- `ui/src/App.tsx` (full rewrite, replacing Plan 01 placeholder):**

Compose all components per UI-SPEC Interaction States (lines 144-152) and PATTERNS.md App.tsx Required Composition:

```tsx
import { useRecommendations } from '@/hooks/useRecommendations';
import { LookupForm } from '@/components/LookupForm';
import { PersonaChips } from '@/components/PersonaChips';
import { RecommendationCard } from '@/components/RecommendationCard';
import { RecommendationSkeletons } from '@/components/RecommendationSkeletons';
import { ErrorAlert } from '@/components/ErrorAlert';
import { EmptyState } from '@/components/EmptyState';

function App() {
  const { state, lookup } = useRecommendations();
  const isLoading = state.status === 'loading';

  return (
    <div className="min-h-screen bg-background text-foreground">
      <main className="mx-auto max-w-4xl px-6 py-16">
        {/* Page title -- Display role: 28px / semibold per UI-SPEC Typography */}
        <h1 className="text-[28px] font-semibold leading-[34px] mb-12">
          Tariff Recommendations
        </h1>

        {/* Form section */}
        <section className="mb-8">
          <LookupForm onLookup={lookup} isLoading={isLoading} />
        </section>

        {/* Persona quick-pick chips (D-08) -- between form and results */}
        <section className="mb-8">
          <PersonaChips onSelect={lookup} disabled={isLoading} />
        </section>

        {/* Result region -- state-driven branch */}
        <section>
          {state.status === 'idle' && <EmptyState />}

          {state.status === 'loading' && <RecommendationSkeletons />}

          {state.status === 'error' && (
            <ErrorAlert httpStatus={state.httpStatus} customerId={state.customerId} />
          )}

          {state.status === 'success' && (
            <div className="grid grid-cols-1 md:grid-cols-2 gap-8">
              {/* Green first, Cheapest second -- stable order per UI-SPEC */}
              <RecommendationCard track="green" data={state.data.green} />
              <RecommendationCard track="cheapest" data={state.data.cheapest} />
            </div>
          )}
        </section>
      </main>
    </div>
  );
}

export default App;
```

Layout decisions:
- `max-w-4xl` (896px content width) centers within the 1280px viewport with comfortable margins. Both cards at ~432px each fit side-by-side with the 32px gap (`gap-8`).
- `py-16` (64px = 3xl spacing) for top/bottom page rhythm per UI-SPEC spacing scale.
- `mb-12` (48px = 2xl) between title and form per UI-SPEC "major section breaks".
- `mb-8` (32px = xl) between form/chips/results per UI-SPEC "form-to-results gap".
- `grid-cols-1 md:grid-cols-2` -- stacked below 768px, side-by-side at 768px+ (UI-SPEC Interaction States line 150).
- Card grid `gap-8` (32px = xl) between the two cards per UI-SPEC spacing scale.

Interaction state mapping per UI-SPEC Interaction States:
- `idle` -> EmptyState
- `loading` -> RecommendationSkeletons (skeleton-first, never blank per UI-02)
- `success` -> Two RecommendationCards (Green first, Cheapest second)
- `error` -> ErrorAlert IN PLACE OF cards (not alongside)

The `PersonaChips` `onSelect` is wired directly to `lookup` -- clicking a chip triggers the full lookup flow immediately (D-08 "one click" presenter safety).

|----------|-------------|
| API data -> RecommendationCard DOM | Untrusted API fields rendered via JSX |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-13 | Information Disclosure | VITE_API_URL in production build | accept (informational) | `VITE_API_URL` is baked into the production bundle at build time. For this demo, the API URL is not sensitive. In a production app, this would need runtime config. Accepted as demo-only risk. |
| T-04-14 | Tampering | Mock fallback active when VITE_API_URL unset | accept | Mock data is hardcoded constants matching the deterministic backend output. No user can modify mock data at runtime. Demo safety net feature, not a vulnerability. |
</threat_model>
