## Decisions Made

- **Invocation-level over constructor-level `structured_output_model`** — RESEARCH.md §Pattern 1 recommended this; it keeps the schema choice visible at the call site and leaves room for a future lenient-schema override at the third-call fallback if message-history extraction ever fails in practice.
- **Reinterpreted D-06(c)** — Under the new API, `ValidationError` is handled inline by `StructuredOutputTool.stream()` (self-correction within one agent turn) rather than propagated to user code. The retry-once-then-per-field-fallback semantics survive by catching `StructuredOutputException` (or `result.structured_output is None`) instead. Strictly better semantically; not a blocker per D-06.
- **Replace `_agent` attribute, not `__call__` method** — [Rule 1 deviation, see below]. The RESEARCH.md Pitfall 1 recipe (`patch.object(agent_mod._agent, "__call__", ...)`) does NOT intercept `instance(...)` calls because Python dispatches dunders via the class descriptor protocol. Corrected the recipe to replace the entire `_agent` module attribute with a MagicMock.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Mock-target recipe in PATTERNS.md did not intercept instance-callable dispatch**

- **Found during:** Task 3 (test_agent_narrative.py rewrite)
- **Issue:** The RESEARCH.md + PATTERNS.md Pitfall 1 recipe instructed `mocker.patch.object(agent_mod._agent, "__call__", return_value=fake)`. This approach is fundamentally broken for mocking instance-callable dispatch: Python resolves `instance(args)` via `type(instance).__call__`, consulting the class's method descriptor — an instance-level `__call__` attribute is silently bypassed. First test run confirmed: assertion `mock_agent.__call__.call_count == 1` failed with `0`, and the real `Agent.__call__` ran against AWS Bedrock (visible in captured stdout: `I'll fetch the savings data for CUST-001 immediately!`).
- **Fix:** Wrote a helper `_install_mock_agent(mocker, *, return_value=None, side_effect=None)` that uses `mocker.patch.object(agent_mod, "_agent", MagicMock(...))` to replace the module-level binding itself with a callable MagicMock. `_agent(...)` in `invoke()` then routes through `MagicMock.__call__`, and `call_count` / `call_args` introspection works correctly. Documented the rationale in the file docstring and the helper docstring.
- **Files modified:** `tests/test_agent_narrative.py` (single file, single atomic commit)
- **Verification:** After fix, all 7 tests pass with `mock_agent.call_count == 1` assertions firing; happy-path test additionally asserts `kwargs["structured_output_model"] is RecommendationResponse` — proves the new-API kwarg plumbing is live.
- **Committed in:** `1663556` (Task 3 commit)
