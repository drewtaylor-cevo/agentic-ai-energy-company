    ```bash
    #!/usr/bin/env bash
    # demo-keepalive.sh — 10-minute rotating-persona ping loop.
    #
    # Beats AgentCore's 15-minute microVM idle timeout by exercising the
    # Phase 7 `?prewarm=1` hot path every 10 minutes, rotating through
    # the three demo personas so the session pool stays warm evenly.
    #
    # Operator pattern (Phase 10 DEMO-RUNBOOK T-30m):
    #   1. Open a tmux pane.
    #   2. export BACKEND_API_URL=https://…
    #   3. bash scripts/demo-keepalive.sh
    #   4. Leave running through end of Q&A; Ctrl-C to stop.
    #
    # Exit: 0 via trap on INT/TERM/HUP. Non-zero on unset env var (set -u).
    # Freeze surface: ~30 LOC, stdlib only; shellcheck zero-warning gate (D-21).

    set -euo pipefail

    : "${BACKEND_API_URL:?BACKEND_API_URL not set}"

    personas=(CUST-001 CUST-002 CUST-003)
    tick_count=0

    trap 'printf "[%s] keepalive stopped after %d ticks\n" "$(date -u +%Y-%m-%dT%H:%M:%SZ)" "$tick_count"; exit 0' INT TERM HUP

    while true; do
      index=$((tick_count % 3))
      persona="${personas[$index]}"
      ts=$(date -u +%Y-%m-%dT%H:%M:%SZ)

      # curl -f fails loudly on 4xx/5xx; -s silences progress; -o /dev/null discards body;
      # -w prints "<http_status> <time_total>" to stdout. `|| echo "000 0"` preserves set -e
      # tolerance on curl non-zero exit (network / DNS / 4xx); we treat it as WARN + continue
      # rather than killing the loop.
      result=$(curl -f -s -o /dev/null -w '%{http_code} %{time_total}' \
        "${BACKEND_API_URL}/recommendations/${persona}?prewarm=1" || echo "000 0")

      status="${result%% *}"
      time_total="${result##* }"
      # Convert seconds (float) to integer milliseconds via awk (portable, no bash float math).
      latency_ms=$(awk -v t="$time_total" 'BEGIN { printf "%d", t * 1000 }')

      if [ "$status" = "204" ]; then
        verdict=ok
      else
        verdict=WARN
      fi

      printf '%s %s %s %dms %s\n' "$ts" "$persona" "$status" "$latency_ms" "$verdict"

      tick_count=$((tick_count + 1))
      sleep 600
    done
    ```

    Line-by-line rationale (do NOT cite this in the SUMMARY; it's for the executor's understanding only):
    - Shebang `#!/usr/bin/env bash` (D-16): env-based shebang for PATH portability; bash (not sh) because we use arrays.
    - `set -euo pipefail` (D-16): `-e` exits on any unhandled non-zero, `-u` errors on unset vars, `-o pipefail` propagates pipeline failures.
    - `: "${BACKEND_API_URL:?...}"` (D-19): bash parameter-expansion idiom — fast-fails with "BACKEND_API_URL not set" on stderr and exits non-zero BEFORE the loop starts. Preferred over an explicit if-test because it's 1 line and emits to stderr automatically.
    - `personas=(CUST-001 CUST-002 CUST-003)` (D-17 + specifics line 263): bash indexed array; index 0 → CUST-001, so tick 0 hits CUST-001 per the deterministic requirement.
    - `tick_count=0`: initialize to 0 so the first tick (before increment) maps to index 0 / CUST-001.
    - `trap '...' INT TERM HUP` (D-18 + Claude's Discretion: include SIGHUP for tmux-pane-close resilience). The trap body uses printf (not `echo -e` — Claude's Discretion says printf is more portable). Variables inside the trap are expanded at trap-fire time, not at trap-set time, because single quotes around the body defer expansion.
    - `while true; do ... done`: infinite loop; only the trap exits.
    - `index=$((tick_count % 3))`: arithmetic expansion; `%` modulo operator. Index range 0-2.
    - `persona="${personas[$index]}"`: array dereference.
    - `ts=$(date -u +%Y-%m-%dT%H:%M:%SZ)`: `-u` flag for UTC; format string produces `2026-04-26T14:23:45Z` verbatim (D-19 sample format).
    - `curl -f -s -o /dev/null -w '%{http_code} %{time_total}'`: canonical curl pattern from CONTEXT.md canonical_refs line 217. `-f` fails on 4xx/5xx (exits non-zero), `-s` silences progress, `-o /dev/null` discards body, `-w` prints the template.
    - `|| echo "000 0"`: on curl non-zero exit (4xx, 5xx, network failure), substitute a sentinel `000 0` so result is always well-formed. `set -e` tolerance: without this fallback, the `result=$(...)` line would abort the script on any curl failure, which violates D-19 "loop continues through termination."
    - `status="${result%% *}"` / `time_total="${result##* }"`: parameter-expansion splits on first/last space. Portable across bash 3+. Avoids subshelling cut.
    - `awk -v t="$time_total" 'BEGIN { printf "%d", t * 1000 }'`: bash can't do float math natively; awk converts e.g. `0.312` → `312`. `printf "%d"` floors/truncates.
    - `if [ "$status" = "204" ]; then verdict=ok; else verdict=WARN; fi`: D-19 semantics — 204 is `ok`, anything else (including the `000` sentinel from curl failure) is `WARN`.
    - `printf '%s %s %s %dms %s\n' ...`: final log line, stdout. Format matches D-19 sample byte-for-byte.
    - `tick_count=$((tick_count + 1))`: increment for next rotation.
    - `sleep 600`: 10-minute cadence per D-18. 600 seconds = 10 minutes. Do NOT change (ROADMAP SC-3).
