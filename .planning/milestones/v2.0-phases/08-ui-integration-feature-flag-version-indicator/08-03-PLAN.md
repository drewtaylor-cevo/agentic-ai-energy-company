<objective>
Ship the `v2.0 · <git-sha>` bottom-right corner marker so that at demo time the presenter can visually verify which bundle is live without opening DevTools (D-14, D-16, D-17). The component is trivial — one span, one className, one interpolated `__GIT_SHA__` — and is rendered once at the root of `App.tsx` as a sibling of `<main>` so it never participates in card layout.

Purpose: Closes UI-07 (UI half delivered here; Plan 01 already shipped the build-time `__GIT_SHA__` define). The indicator is the primary stale-bundle diagnostic for live demo — it MUST match the commit SHA of the shipped bundle.

Output: `VersionIndicator.tsx` + `VersionIndicator.test.tsx`, one `App.tsx` edit adding the render. No other changes.
</objective>
