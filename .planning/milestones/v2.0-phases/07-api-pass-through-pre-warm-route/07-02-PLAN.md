## fn.current_version behaviour (07-RESEARCH.md §Pattern 3)

- `fn.add_alias("live")` defaults `version=fn.current_version` — same as `lambda_.Alias(self, "LiveAlias", alias_name="live", version=fn.current_version)` but terser.
- CDK auto-publishes a new immutable Lambda version on each code change; the alias rolls forward automatically on each `cdk deploy`.
- Only supported for `Code.fromAsset` / `Code.fromInline` — the construct uses `Code.from_asset("api_lambda", bundling=...)`, so supported.
- `current_version_options.removal_policy` defaults to `RemovalPolicy.DESTROY` — old versions cleaned up on supersession. The Phase 7 plan does NOT need to set this explicitly.
