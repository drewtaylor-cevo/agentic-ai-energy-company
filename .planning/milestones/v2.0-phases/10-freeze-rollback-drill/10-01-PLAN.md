```json
      "Resource": "*"
    }
  ]

```

updates during the freeze window"). File-name-per-stack keeps the ceremony command explicit about
*which* stack is being locked — NOT a shared file referenced three times. Do NOT consolidate.

## Shell helper contract (PATTERNS.md lines 107-142 analog = scripts/demo-keepalive.sh lines 1-19)

Both `scripts/hash_dist.sh` and `scripts/hash_synth_assets.sh` MUST:
- Start with `#!/usr/bin/env bash`
- Have a multi-line `#` header: one-line purpose, operator usage pattern, exit-code discipline,
  freeze-surface note, citation of the 10-RESEARCH.md section the pattern is derived from
- First executable line: `set -euo pipefail`
- Fast-fail on missing arg: `: "${1:?usage: <script> <directory>}"`
- Body is a single compound command that prints exactly one 64-char lowercase hex line on stdout
- Exit code: 0 on happy path; non-zero (via `set -e`) if the `$1` arg is missing or the directory
  doesn't exist
- Must pass `shellcheck` with zero warnings

## hash_dist.sh body (D-09 REVISED — RESEARCH.md §Q4 Example 1 fallback approach)

```bash
(cd "$1" && find . -type f -print0 | LC_ALL=C sort -z | xargs -0 sha256sum | sha256sum | awk '{print $1}')
```

Rationale: per-file sha256 → sorted-z list → hash-of-hashes. No tar, no mtime leakage. Proven
empirically stable within a single build in RESEARCH session; this plan adds the cross-rebuild
empirical proof as task 10-01-04.

## hash_synth_assets.sh body (D-08 REVISED — RESEARCH.md §Q3 Pitfall 3 mitigation)

```bash
(cd "$1" && find . -type f -not -name '*.pyc' -not -path '*/__pycache__/*' -print0 | LC_ALL=C sort -z | xargs -0 sha256sum | sha256sum | awk '{print $1}')
```

Same pattern as `hash_dist.sh` but excludes Python bytecode caches (they carry build timestamps
in their headers per RESEARCH.md §Q3 and break synth-twice reproducibility).

## Exit taxonomy (Phase 9 convention, PATTERNS.md "Shared Patterns")

0 = happy path (hash printed); non-zero via `set -e` when `$1` missing or directory unreadable.
These scripts COMPUTE — they don't GATE — so there's no explicit `exit 1` / `exit 2`.
